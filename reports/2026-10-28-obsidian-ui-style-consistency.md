# 2026-10-28：Obsidian 本地保存界面样式一致性修复

## 现象与根因

用户截图中的新设置按钮呈浏览器默认灰色方框，预设表单出现大边框。其它设置导航和卡片正常，说明不是全站主题失效。

新增 `Settings.tsx` / `SaveButton.tsx` 使用了没有 `.button` 的原生按钮；设置表单还使用未重置的 `fieldset` / `legend`，因此显示浏览器默认边框。属于新增界面漏接项目设计系统，不是有意新增设计。已有共享 Modal 是自绘 `section role="dialog"`，本次没有发现使用原生 `<dialog>`。

旧测试只覆盖点击、取消、权限、冲突和数据状态；没有断言设计系统类，也没有完成真实截图验收。所以测试通过不能证明视觉正确，这是上一轮交付的覆盖缺口。

## 修复范围

基线先确认工作区 clean，fetch 后本地及远端同为 `3518847582ac15a9692143b2ba033a3914a3c650`。不合并、变基或覆盖外部更新。

- 全部新增按钮复用 `.button`，主要保存操作复用 `.primary`，次要列表操作复用 `.small`。
- 预设列表使用既有 `.config-card`、`.button-group`；表单复用 `.form-stack`、`.field-heading`、`.form-grid`、`.form-hint`。
- 去除 `fieldset` / `legend`，改用有 accessible name 的 `role="group"`；将 busy 显式传给输入和浏览/保存按钮，保留原禁用语义。
- 保存弹窗继续复用共享 Modal；操作集中于 `.modal-actions.button-group`，支持窄屏换行；长下载说明移至提示文字，不让 nowrap 按钮撑宽弹窗。
- 没有新增色值、边框体系、全局 CSS 覆盖或下载/权限业务变更。颜色、控件圆角、间距及明暗主题继续由既有全局设计 token 决定。
