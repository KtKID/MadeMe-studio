# Obsidian 同目录仅 Markdown 保存选项（2026-10-29）

两张用户截图已按 Library 流程下载并查看。用户要求“仅下载 Markdown”改复选框，不另选下载路径；底部与操作统一靠右，主按钮改“保存”。

## 行为

- 支持目录授权的保存弹窗，底部顺序为“仅下载 Markdown → 取消 → 保存”，共享右对齐、可换行操作组。复选框标签文字可点击，保留 checkbox 原有 16px 尺寸，不受普通 input 100% 宽度影响。路径旁“其他位置”仍在原处。
- 默认未勾选，仍保存文字与图片。勾选只影响本次保存，同一已选根/文章子目录、同一主按钮和安全写入流程；不触发普通下载、不额外打开目录选择器，不修改预设。
- 选项由 Zod `saveOptionsSchema.markdownOnly` 声明，缺省即原行为。存储适配器跳过媒体目录访问、fetch 与附件写入，仅提交正文及其安全清单；已有图片及媒体映射不删除、不改写，不生成缺失本地 asset 链接。
- UI 在纯正文时把网站相对图片地址解析为同一网站绝对 URL；外部原链接保留，不添加访问令牌。链接仍受网站原有权限/联网限制，不声称离线图片可用。
- 同篇完整保存切纯正文、重复纯正文、再切完整保存保持文章 ID→路径与摘要冲突检测。无预设仍需先选并校验目录。
- 新开弹窗默认未选；切换预设保留当次勾选；busy 禁止切换/重复保存；选项变化清除旧结果与冲突确认状态，下一次保存重新取当前稿。
- 不支持目录授权的浏览器仍提供明确“下载 Markdown 文件”能力降级，不伪装同目录保存。
