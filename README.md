# MadeMe Studio

MadeMe Studio 是一个面向个人作者的 AI 写作、内容管理与发布工作台。

## 项目目标

让作者在网站前台直接编辑文章，并通过统一的内容系统完成整理、配图和发布。公开网站面向读者，AI 能力服务于作者，不提供访客聊天机器人。

## 已确定的技术方向

- **Astro**：网站页面、路由与服务端接口。
- **BlockNote + React**：块式富文本编辑器，前台与后台共用编辑能力，不使用 Novel。
- **TypeScript**：业务代码与类型约束。
- 模块化划分内容、编辑器、媒体、AI、权限、发布集成与主题展示。

## 第一版计划

- 文章前台直接编辑、后台管理，区分保存草稿与正式发布。
- Markdown、富文本、多媒体上传与嵌入。
- AI 辅助改写、润色、摘要、标签及配图。
- 公开、草稿、密码访问、链接访问等发布状态。
- 搜索、分类、置顶、软删除与恢复。
- 主题配置及移动端适配。
- 受控发布 API，以及浏览器剪藏、Obsidian 和 Skill 发布入口。

## 安全原则

写入操作由服务端鉴权；模型密钥不进入客户端或仓库；限制文件上传及外部请求；保护非公开内容与附件；避免并发编辑覆盖。

不会默认导入或公开私人 Obsidian 笔记，只发布作者明确选择的内容。
