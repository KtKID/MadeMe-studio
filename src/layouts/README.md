# 布局与主题模块

`Base.astro` 提供语义 HTML、语言、视口、站点主题与跳转主内容入口。`Studio.astro` 提供响应式工作台侧边栏、导航与统一页脚。样式位于 `src/styles/global.css`。

强调色仅接受十六进制颜色，避免动态 CSS 注入。主题为 paper / ink / garden / mono，移动端需验证导航与表格不溢出。

## 后台导航性能

后台列表、媒体、设置和连接页面启用 Astro ClientRouter，复用已加载的客户端模块，减少整页刷新。新建和编辑文章保留完整文档导航，继续使用原生 beforeunload 保护；没有通过页面缓存绕过身份验证。主题监听在每次页面交换后清理并重绑，防止重复监听或旧根节点残留。

切页仍会请求服务端，因此不承诺消除托管层网络延迟。不得以此将私人 HTML 改为公共缓存。
