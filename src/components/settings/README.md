# 站点设置模块

`SettingsPanel.tsx` 管理站点文案、导航、四种主题、字体、强调色、供应商模型元数据与提示词。自定义代码仅进入无权限 iframe 沙盒，不进入编辑器 DOM 或公开页面。

服务端密钥不在本组件采集或保存。未连接服务商显示明确未配置状态。服务器 Zod 协议是最终写入边界。

## 待验证

设置保存后重新加载保持值；非法导航协议被拒绝；四主题桌面/移动布局；沙盒无法读取父窗口。实现先于追加 TDD 要求，后续修改须先补用例。

## 外观和模型的独立维度

`theme` 只决定首页结构（编辑刊物 / 时间线 / 画廊 / 极简）；`skin` 决定配色；`mode` 决定明暗；`font` 决定正文、标题和编辑器字栈。默认微软雅黑、暖黄、跟随系统。`accent:null` 表示无自定义覆盖；“恢复皮肤默认”会明确提交 null，不覆盖其他字段。

`model-options.ts` 只负责共享 Provider 枚举的展示名称。支持 Google Gemini、OpenAI、OpenRouter、SiliconFlow、Cloudflare AI，文本与图片模型独立；空白图片模型省略。模型列表从已保存的服务端配置读取，不接收任意 baseURL 或密钥。

## 并发保存策略

设置写入仅提交当前窗口相对已确认基线的 dirty 字段，不发送整份旧设置。响应按字段与提交快照比较：请求后又输入的字段保留并继续显示未保存；未改字段采纳服务器新值。不同字段的跨窗口修改可独立合并。同一个字段（包括导航/模型数组）在多窗口同时编辑时，采用最后一次成功保存覆盖的明确策略；不宣称提供字段内自动协同。

设置页禁用客户端路由并强制完整进入；尚未保存时，链接跳转、浏览器前进/后退、地址跳转和刷新均使用浏览器原生离开保护，取消后保留输入。不得用 Astro preparation 的 preventDefault 代替导航取消。相关监听随 dirty 状态和组件卸载清理，避免成功保存后继续误拦截。

链接离开另有捕获阶段的显式确认，取消保留输入；确认放行该次原生卸载，避免再次弹窗。浏览器历史/刷新/地址跳转仍走原生保护，不引入 Astro 路由；实际浏览器验收需分别记录显式 confirm 与 beforeunload，不能混算。

模型列表读取按服务商 ID 使用同步锁与独立忙碌状态，防止同帧重复请求以及先完成的服务商清除另一请求的占位。失败后释放对应锁；不调用收费生成接口。
