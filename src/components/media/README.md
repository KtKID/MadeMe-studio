# 媒体模块

`MediaLibrary.tsx` 处理文件上传、搜索、生成历史（最多 100 项）、插入/封面/下载。图片裁剪用 Canvas 创建 JPEG 新文件，保留原始图片，支持比例、缩放、水平与垂直定位。

文件的 MIME、尺寸、访问权限最终由服务器校验。前端不能把未发布媒体变为公共资源。跨域图片无法安全读取时明确报错。AI 图片缺少后端服务配置时禁用生成，不返回占位图假装成功。

## 手工/E2E 验收清单

小型 PNG 上传 → 搜索找到 → 插入正文 → 设封面 → 裁剪成新文件 → 原文件仍存在。检查未授权请求、超大文件与伪 SVG 被拒绝。真实供应商生成需要安全配置，未配置时只验证禁用状态。

上传控件的 accept 来自 `src/shared/contracts.ts` 的 `acceptedMediaMimeTypes`，与服务器同一来源，包含 AVIF、Office OpenXML、ZIP、EPUB、CSV。生成图片对话框允许明确选择已配置服务商及其独立图像模型。

`crop-state.ts` 验证源图已成功解码且当前比例/缩放/位置版本已绘制。未载入、404、零尺寸或过期回调均不能导出；保存函数自身再次校验，不能只依赖按钮禁用。浏览器 Canvas 完整管线验收见 `tests/e2e/media.spec.ts`，其真实执行状态单独报告。

## SSR 初始列表

独立媒体页接收授权后读取的 `initialMedia` 与 `initialError`。`[]` 表示成功加载空列表，挂载不再请求；未传 `initialMedia` 的编辑器弹窗保留原 GET 行为。SSR 错误直接显示并记录导航失败，不能作为空列表 ready。上传与裁剪仍更新本地列表，不增加共享缓存。

## 交互链路回归

上传、图像生成、裁剪导出使用同步单飞锁，阻止同一个 render 内重复事件产生重复 POST。请求函数自身校验图像配置与提示词；失败释放锁并保留可重试输入。初始媒体 GET 迟到时合并而非覆盖等待期间的新上传。生成/裁剪已提交时取消按钮禁用，避免把不能撤销的服务端写入误称为已取消。

`tests/ui/media-clicks.test.tsx` 在 jsdom 中真实渲染 MediaLibrary 并发送 DOM 点击/change，覆盖筛选、插入、封面、下载属性、未配置生成、上传取消/重复/失败重试、裁剪未就绪取消、初始 GET 竞态与生成失败重试。网络为隔离 mock；真实 Canvas 绘制、媒体解码和供应商仍需独立浏览器/账户验收。
