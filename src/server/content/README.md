# 文章与版本模块

## 分层

- `service.ts`：草稿、发布、撤回、软删除、恢复、修订恢复的业务约束。
- `repository.ts`：仓库接口与 D1 实现；业务层可独立验证。
- `validation.ts`：块树尺寸/深度、链接协议、嵌入提供商与媒体引用检查。
- `markdown.ts`：保守 Markdown 导入，生成 BlockNote JSON；HTML 作为字面文本，不执行或直接插入 DOM。

## 数据语义

`draft` 与 `published` 是独立快照。保存只推进草稿版本，必须明确发布才改变访客内容。撤回使用独立操作。公开列表仅含未删除的 public 已发布快照；password、unlisted、草稿不进入列表。

修改操作必须提交当前 `version`。D1 通过条件 UPDATE 做 CAS，再在同一批次事务中按随机 mutation 标识插入修订，失败更新不会制造修订。冲突返回 409。

修订恢复仅修改草稿，不回退当前发布快照或密码；恢复后需再次发布才能对访客生效。删除为可恢复软删除，文件读取也检查文章删除状态。

## Markdown 范围

支持段落、标题、粗体/斜体/删除线/行内代码、HTTPS/邮件链接、列表、任务、引用、围栏代码、独立图片和表格。保留文字优先；复杂嵌套和自定义 Markdown 扩展不承诺无损转换。

## 测试

`posts.test.ts` 使用真实 SQLite 执行迁移和 D1 参数化 SQL，验证发布隔离、CAS、修订原子性、密码快照、可见性、删除/恢复/撤回及危险内容拒绝。
