# 文章与版本模块

## 分层

- `service.ts`：草稿、发布、撤回、软删除、恢复、修订恢复的业务约束。
- `repository.ts`：仓库接口与 D1 实现；业务层可独立验证。
- `validation.ts`：块树尺寸/深度、链接协议、嵌入提供商与媒体引用检查。链接与嵌入规则来自 `src/modules/content-check`，拒绝时返回 422，`message` 为按块定位的中文原因（如“第 2 个视频块……”），`details.problems` 给出 blockId / blockType / ordinal，并记 `content.rejected` 日志（不含 URL）。
- `markdown.ts`：保守 Markdown 导入，生成 BlockNote JSON；HTML 作为字面文本，不执行或直接插入 DOM。

## 数据语义

`draft` 与 `published` 是独立快照。保存只推进草稿版本，必须明确发布才改变访客内容。撤回使用独立操作。公开列表仅含未删除的 public 已发布快照；password、unlisted、草稿不进入列表。

修改操作必须提交当前 `version`。D1 通过条件 UPDATE 做 CAS，再在同一批次事务中按随机 mutation 标识插入修订，失败更新不会制造修订。冲突返回 409。

修订恢复仅修改草稿，不回退当前发布快照或密码；恢复后需再次发布才能对访客生效。删除为可恢复软删除，文件读取也检查文章删除状态。

## Markdown 范围

支持段落、标题、粗体/斜体/删除线/行内代码、HTTPS/邮件链接、列表、任务、引用、围栏代码、独立图片和表格。

- 连续列表行按前导缩进生成 `children`，支持有序、无序、任务项混排和退回同级；制表符按四个空格处理，空行或非列表行结束当前列表层级。
- 表格按未转义的竖线分列；`\|` 保留为单元格文字，反斜线按奇偶配对。
- 成对强调可组合粗体/斜体，并保留链接标签样式及外层样式。链接内容仅生成 styled text，不生成嵌套链接；行内代码不递归解释格式。
- 导入原文上限为 1,000,000 个 UTF-16 代码单元，列表最多 10 层，行内格式递归最多 16 层；超限显式报错，不静默截断。生成内容仍必须通过共享 Zod 协议和文章尺寸/深度校验，原文未超限不代表生成 JSON 必然符合存储上限。

这是有界 Markdown 子集，不是完整 CommonMark/GFM 实现。多段落列表项、列表中的围栏/表格、任意括号嵌套链接、完整强调分隔符规则与自定义扩展不承诺无损转换。表格代码跨度内的竖线也需显式转义。原始 HTML 只作为文字，不作为 HTML 执行。

## 测试

`posts.test.ts` 使用真实 SQLite 执行迁移和 D1 参数化 SQL，验证发布隔离、CAS、修订原子性、密码快照、可见性、删除/恢复/撤回及危险内容拒绝。

`markdown-escapes.test.ts` 和 `markdown-fidelity.test.ts` 覆盖转义标点、混合列表层级、表格转义竖线、强调/链接组合、安全文字输出及长度/深度边界。
