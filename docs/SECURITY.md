# 安全边界

## 身份与部署

当前私有预览使用托管平台的身份分发，服务端验证明确的作者 ID 或作者邮箱。不得在普通公网 Worker 上直接信任客户端自报的身份头；独立部署必须接入会清洗这些头部的受信任身份网关。缺少作者配置时写入失败关闭，不采用首个访问者自动成为管理员。

开发身份仅在显式 development 配置和本机主机名同时满足时可用，不得用于公网。真实密钥只配置在服务端运行环境，不提交 Git、不进入客户端，也不放到公开网页。

## 内容与文件

草稿和已发布正文独立保存；保存不等于发布。密码或链接访问内容不进入首页、RSS 和 sitemap。链接访问不是密码保护，拿到链接的人可访问。

上传有体积、MIME 与签名限制；HTML/SVG 等可执行内容不直接作为页面发布。附件读取同时校验文章权限及已发布引用。富文本结构通过 Zod 验证，阅读端不插入任意 HTML。自定义代码仅在受限沙箱预览，不注入编辑器或公开正文。

## 外部工具

发布 Token 按最小权限使用、可撤销、有过期时间。无读取权限的写入回执只有 ID 与版本，不返回私人草稿。插件只发布明确选中的内容，不扫描或同步整个 Obsidian 库。

私有预览的外层访问控制可能阻止外部插件直接访问；真实宿主联调应使用明确授权的发布环境，不能为测试擅自改为公开。

## AI 与费用

端点采用固定官方主机白名单、禁止凭据跟随重定向，响应有大小和时间界限。客户端看不到服务端密钥。

请求次数、输出 token 与超时限制不是提供商账单的硬性金额封顶。取消界面操作不能保证已发出的提供商请求立即停止或不计费；配置真实密钥前应设置提供商预算。

密码访问需要部署者安全配置至少 32 字符的 SESSION_SECRET；缺配置时不会允许发布到密码模式。此仓库没有真实签名密钥或模型凭据。

## 验证限制

自动测试不等于正式安全认证。浏览器、真实托管身份、外部宿主和模型服务需要分别验证，不以模拟协议测试冒充生产联调。
