# 全站交互链路覆盖矩阵

审查时间：2026-10-27。初始审查基线：`ac1e937`（写作返回修复之后）。本文件是交互入口清单、证据索引和待补测试矩阵，不是“所有按钮已点完”的验收证书。后续修复及实测应补充具体用例与结果，不把静态检查、测试源码或接口测试换算为浏览器通过率。

## 口径与安全边界

每个入口至少观察：**入口可达 → 状态变化 → 请求/导航 → 最终结果**。有副作用的入口另外检查：取消、重复点击、失败重试、响应延迟期间继续输入/离开、身份失效。不能只断言按钮存在或 HTTP 返回 200。

- **U**：已有单元、状态机或组件夹具测试源码；本轮开始前记录的总测试为 254 项，不代表本矩阵每项已执行。
- **D**：本轮实际 React/jsdom DOM 点击测试（`tests/ui`）；API、BlockNote、Canvas、浏览器导航等边界采用 mock，不能证明真实浏览器布局或端到端写入。执行结果见下文，未部署补丁与线上版本分开记录。
- **H**：已有 HTTP / Worker 流程测试；不等于按钮点击链路已跑。
- **E**：已有 Playwright E2E 源码；当前独立浏览器运行受环境限制，不能据此称已执行。
- **B**：`VERIFICATION.md` 或本轮父任务记录的实际云端浏览器检查；仅覆盖明确写出的路径。
- **缺口**：未找到对应前端交互断言，或只覆盖正常分支。并非断言一定存在缺陷。

写入、删除、发布、恢复、访问令牌、付费 AI 均只能用隔离测试实例/模拟协议，不盲点生产数据。线上只读和不保存的临时输入可以检查取消链路；不得把用户文章当测试夹具。访问令牌创建仍涉及持久授权，测试不得自动创建真实令牌。服务器接口测试和 UI 测试分别记账。

## 优先风险记录（初始发现，当前处理进度见后表）

以下是基线源码可追踪的风险，不以静态推断冒充浏览器已复现：

1. **R1 初始文章错误被空状态吞掉（已定位源码）**：Dashboard `initialError` 只用于测量标失败，`error` 却初始化为空字符串，UI 不呈现服务器初始列表错误。媒体、令牌采用 `useState(initialError)`。应组件断言初始错误显示且不能把失败当空库成功。
2. **R2 编辑内容被延迟替换覆盖（高优先）**：Editor `reload`、`restore` 在请求完成后无条件 `replaceBlocks` 和 `markClean`；`importMarkdown` 等待 `file.text` 后替换正文。期间仍能编辑，且恢复不是保存事务锁。补“请求中输入→响应返回→新输入不能悄悄丢失”的组件用例，及操作之间互斥/过期结果规则。
3. **R3 文章并发操作锁不足**：Dashboard 用单个 busy ID，跨行请求及 finally 相互清 busy；Editor 撤回发布没有保存同步锁。服务端 CAS 可以保护库，但 UI 不应重复提交或显示误导忙碌状态。需快速重复及乱序结果断言。
4. **R4 AI响应与当前操作错配**：runAI 的响应只写 `aiText`，applyAI 读取当前 `aiAction`。请求期间切换动作/重开面板，旧结果可能被按新动作应用。必须 mock 延迟服务，绑定响应来源并禁止旧任务污染；不能为测试调用收费模型。
5. **R5 媒体弹窗关闭不是请求取消**：裁剪/生图请求期间取消或切换面板后，迟到回调仍可能关闭新弹窗/清除新prompt，或已产生文件。需明确“关闭UI”与“停止远端操作”的区别，测试活动代次、重复请求、部分成功；不要误承诺取消后绝无写入。
6. **R6 令牌列表/表单并发**：revoke 使用闭包 `tokens.filter`，两个撤销请求乱序会把已删除项带回UI；create只禁用按钮无同步锁，旧创建响应会 `setOpen(false)/setName('')`，可能影响重开表单。已有一次性secret防复活测试不等于这些状态已覆盖。
7. **R7 文档证据口径过期**：根 README 仍说云浏览器只能看到登录门，与后续已登录实测矛盾。应保留“完整E2E未验收”的事实，但不能重复陈旧阻塞。这属于交付可信度问题，不是运行代码缺陷。

## 可维护控件清单与 CI 准入建议（尚未实施）

不要把 `onClick` 数量当覆盖率。建议将上表 ID 作为稳定的**行为标识**，维护机器可读控件清单，字段包含：模块、稳定 ID、路由/可见角色、触发方式（click/submit/change/keyboard/history）、结果类型（导航/写入/下载/仅 UI）、风险等级、必测分支、对应测试 ID、浏览器证据版本、允许遗漏原因。重复文章行只登记行为族，测试用多实例验证对象 ID；BlockNote 动态菜单另建运行时展开清单。

CI 应执行以下准入，而不是声称自动点完所有按钮：

1. AST 收集第一方 JSX/Astro 的 button/a/form、事件 handler 与自定义可交互组件；动态 DOM 和第三方菜单用显式补充项。与已登记入口差异比较，**新增入口未映射到行为 ID 或带负责人说明的例外则失败**，同时检查孤立/已删除清单项。
2. 每个高风险写入口要求取消、失败、重复和迟到响应的 DOM 用例 ID；文件/导航/支付/凭据类额外列浏览器验收要求。不能仅因有测试文件就认为该分支有断言。
3. 测试 manifest 校验清单引用的测试 ID 存在，运行结果关联当前 commit；源码扫描不能证明测试实际执行。真实浏览器证据同样绑定部署版本，旧版本证据不可冒充新版本通过。
