# 独立 Obsidian 仓库连接：需求与验收 TODO

最新用户指令取代上一轮预设复用方案：导入不得依赖可删除的笔记导出预设。

## 设计约束

- 后台新增独立“Obsidian 仓库”设置，MVP仅一条导入连接，浏览器原生目录handle+显示名，不是字符串路径。独立同源本地存储，不拷贝/迁移旧预设或继承其授权。
- 用户明确选择/替换仓库取得read能力，校验直属 `.obsidian`；清除仅删除连接记录，不删文件/笔记预设。失效明确read重新授权，不请求写权限。
- 原导出预设的数据结构、存储、增删改名和导出行为不变；导入使用独立连接，原预设不存在或删除不影响。
- 已配置连接→只指定一篇MD原生handle→根resolve确认真实路径→自动读根内跨目录图/GIF/本地视频→保留远程媒体链接→逐项数量、名称、路径、类型、状态→上传保存刷新。只读取引用，不全库上传，不改原文。
- 更换/清除连接使旧导入结果失效，不能把旧根迟到结果应用到编辑器；取消/切换/新增输入仍受保护。根内../允许，越根、同名歧义、缺失与权限失败明确停止。
- 网站自定义按钮/Modal统一。连接只在当前浏览器/域名，Site不继承正式博客连接。
- 不绕过当前云浏览器真实showDirectoryPicker的NotAllowedError；受控OPFS原生handle测试与真实外部OS授权分开报告。
