# 复用笔记预设导入 Markdown：需求与验收

## 用户目标

已有“同步 Obsidian → 笔记预设”及目录句柄时，点导入、明确选择预设中的一篇MD，自动匹配并读取该篇引用的图片/GIF/本地视频；不再把逐个补选文件当正常完成路径。远程媒体链接保留，界面列数量、名称、类型、仓库相对路径和状态。

## 必须保持

- 复用 `obsidian-local/presets.ts` 的同源 IndexedDB `mademe-obsidian-local` / `presets` 和 `{preset,handle}`，不另建关联或持久默认ID；不把导出的list[0]作为导入用户确认。
- 用真实FileHandle与根resolve确定唯一仓库路径。多个预设明确选择，文件重名不按正文/文件名猜测。只读当前MD和实际引用附件；不写本地文件，不全库上传，不取写权限。
- 已有read权限只query、不反复request；失效时用户明确点“重新授权此预设”，请求mode:read。缺预设/不支持时清楚提示现有设置入口。
- 根内 `../` 跨目录允许，越根/危险协议/同名歧义/缺失安全失败；重复引用只上传一次；取消和切换MD不应用旧结果，保留编辑器输入。
- 正式博客和独立Site是不同origin；预设和授权不能自动跨origin继承。Site用户需在Site同源设置里关联一次测试仓库。
- 网站Modal、按钮和Dropdown统一；不暴露原生file input。普通单文件File不能resolve，不当作自动附件链完成。
