# 第一版开发清单

## 执行约定

- 技术栈：Astro、TypeScript、React、BlockNote；协议以 Zod 为唯一来源。
- 注释和模块说明用中文，每个模块内有 README，根 README 提供索引。
- 新增功能先定义失败用例，再实现，运行单元、冒烟和端到端验证。
- 最初研究草稿先于本约定生成，不能伪称这些草稿遵循了测试先行。正式分模块集成时重新建立验收记录。
- 基础框架先提交，其后每个模块独立提交；不混入密钥、个人笔记、构建缓存。

## 按依赖顺序交付

- [ ] 01 基础：框架、真实编辑器、Zod、构建脚本、测试入口、模块文档。
- [ ] 02 权限：作者绑定、服务端鉴权、CSRF、限权且可撤销的 API Token。
- [ ] 03 内容：草稿与发布快照、分类标签搜索置顶、版本冲突、回收站与恢复。
- [ ] 04 编辑器：前台直接编辑及后台复用、块编辑、Markdown、未保存保护。
- [ ] 05 媒体：受控上传、图片音视频文件、嵌入、裁剪及封面、附件权限。
- [ ] 06 AI 写作：选区操作、标题摘要标签网址、模板模型参数、失败保护及限额。
- [ ] 07 AI 配图：提供商、选区生成、100 条历史、搜索插入替换及封面。
- [ ] 08 外观：暖黄色默认、四套皮肤、明暗模式、微软雅黑优先字体，三者解耦。
- [ ] 09 站点配置：导航、分类、SEO、RSS、sitemap、受限自定义代码。
- [ ] 10 外部集成：Chrome 选区剪藏、Obsidian 单篇选择、Skill/CLI，默认只建草稿。
- [ ] 11 总体验收：真实构建、测试、私有预览、完整源码及限制说明。

## 测试要求

单元：协议拒绝非法输入、权限、快照隔离、版本409、软删除恢复、配置解耦。

冒烟：进程启动、首页200、健康API、编辑器加载、构建入口存在。

HTTP端到端：通过真实HTTP请求新建、保存、发布、读取、修改草稿、恢复，验证未发布内容不会泄露。

浏览器端到端：前台进入编辑、输入、保存、发布、重载；媒体上传；切换模式/皮肤/字体；取消与失败处理。未执行的浏览器测试不得记为通过。

外部服务：无模型凭据时仅验证缺配置错误和模拟服务协议，不宣称真实模型生成通过。
