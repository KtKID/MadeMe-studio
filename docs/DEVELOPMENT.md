# 第一版开发清单

## 执行约定

- Astro、TypeScript、React、BlockNote；Zod 为业务协议唯一来源，不另写同义协议。
- 模块边界清晰，注释与说明用中文；每个业务模块自带 README，根 README 建立索引。
- 基础框架先提交，随后按协议、存储、权限、内容、媒体、AI、API、界面及外部集成分模块提交。
- 新增回归先记录失败，再修复实现。部分初始研究草稿与界面实现早于测试先行要求，不能把全部历史声称为严格 TDD；具体模块如实记录顺序。
- 不提交密钥、私人笔记、运行数据库或构建缓存。

## 后续性能优化（不属于本版本）

- [ ] 文章列表缓存优化：每次切换到文章部分都要重新读，需要做缓存优化。
- 本版本先不做缓存；保留当前按请求读取文章数据的行为。后续设计缓存时须明确发布/保存后的失效规则及作者私密数据隔离，不能用共享缓存泄露草稿。

## 测试层次

1. 单元与后端回归：协议拒绝非法输入、鉴权、快照隔离、版本 409、撤销恢复、外观与设置解耦。
2. 真实 Worker HTTP：构建产物运行于本地 Worker，使用真实本地 D1/R2，验证创建、保存、发布、读取、媒体及访客隔离。
3. 浏览器 E2E：通过真实页面与 BlockNote 交互，不能用 API 测试替代。
4. 外部集成：协议、CLI 冒烟、构建/类型检查与真实宿主安装分别记录。
5. 外部模型：无凭据时仅验证缺配置错误与模拟上游协议，不发起收费调用或伪造生成结果。
