# MadeMe 后台导航性能优化报告

日期：2026-10-27｜最终代码：`5f375ae60b08b22884d80ed1caadefc61fb26255`

## 结论与验收边界

目标是四个后台 tab 从点击到内容可操作均低于 1 秒。在本轮实测条件下，最终 40 次点击全部达标；将可见图片加载也计入后，同样 40/40 低于 1 秒。内容最慢 51.00 ms，可见图片最慢 385.20 ms。

这一结论仅适用于既有云端 Chrome、1165×757 CSS 像素视口、3 篇文章和 3 个媒体、初次后台加载完成后的四个 tab 切换。没有清理浏览器缓存，也没有控制 CDN／服务端缓存状态；不能扩展为任意网络、冷启动或大规模真实文章下的保证。多文章浏览器场景尚未实测。

首开仍未达到 1 秒：最终新部署首次进入后台为 4006.50 ms，计入可见图片为 4016.20 ms。常驻工作区把一部分成本移到首次加载，不能用切换成绩掩盖首开成本。

## 测量口径

三个阶段使用同一浏览器、同一 tab、同一数据集及顺序，循环“文章 → 媒体 → 设置 → 集成 → 文章”10 轮。每阶段40次点击，每个目标10次；进入后台的 initial 样本单独列出，不混入点击统计。每次等待内容与可见图片状态均 ready 后，再点击下一项。

contentInteractive：点击事件开始计时，直到目标内容／数据就绪、React 提交或水合完成，再经过双 requestAnimationFrame。它不是只测 URL 改变，也不是工具调用耗时。visibleImages：另外记录目标主内容可见图片加载成功的时间，不代表所有屏外图片或全部网络资源完成。

p50 为中位数；p95 使用 nearest-rank。每个 tab 仅 n=10，所以 p95 与本组最大值相同，不应当作长期线上 p95 承诺。表格保留两位小数；改善率使用未四舍五入数据计算，公式为（基线 - 最终）/ 基线。

统一模块位于 `src/modules/navigation-performance/`，通过 `?perf=1` 开启诊断。采样只存路由、耗时与状态等元数据，不采集文章正文，不发送外部分析事件。

## 为什么原来慢以及如何优化

### 阶段一减少无效数据与串行请求

文章列表原先读取完整草稿／发布快照，bootstrap 还包含列表不需要的正文。现在 `D1PostRepository.listSummaries()` 使用 SQL JSON 字段投影，仅提取列表所需的12个字段，并由 Zod 摘要协议约束。编辑文章时仍按需读取完整正文，公开文章仍使用发布快照，没有通过删除内容制造速度提升。

媒体与集成页原先在 SSR／鉴权后，还要等待客户端水合，再请求媒体或令牌元数据。现在作者权限检查后，由服务端提供初始数据，消除首次 mount 的额外请求瀑布；令牌只传元数据，不传 secret。日期格式器复用，避免每行反复创建 Intl.DateTimeFormat。

阶段一降低数据层与部分页面成本，但页面间的导航、初始化、水合仍重复发生。实测不能保证四个 tab 都在 1 秒内，因此继续进行第二阶段。

### 最终阶段使用模块化常驻工作区

保留 Astro + React，不引入新的前端框架或全局状态库。`StudioWorkspace.astro` 统一加载工作区初始数据，`StudioShell.tsx` 负责四个 tab 的激活状态、地址／历史及离开保护；原有文章、媒体、设置、集成组件继续各自负责业务和局部状态。

切换时复用已挂载组件，不再为了四个工作区页面反复请求文档和重新水合。非活动面板 hidden／inert，不接收用户交互。编辑器、新建文章、登录及公开页面仍保留独立页面边界。

没有新增持久化私有数据缓存，也没有为私有 HTML 开共享缓存。常驻页面中的内存复用不是跨会话缓存；数据变更仍走原有服务端接口。未用淡入动画隐藏等待时间。

## 合成多文章数据层微基准

这是本地 Node + 内存 SQLite 测试，不是浏览器 tab 耗时，也不是线上 D1 网络时间。每篇正文为10,240 UTF-8字节，数据库保留草稿与发布快照；每档5次预热、30次采样。测量 loader + JSON.stringify，payload 为未压缩 bootstrap JSON，不含 HTTP／HTML。最终工作区加载器包含媒体与令牌查询，但此测试的媒体和令牌数量均为0。

## 安全与回归验证

服务端授权、CSRF 与私有响应 no-store 保留；前端隐藏面板不是权限边界。工作区在隐藏／pagehide 时遮蔽私有内容；恢复时通过 no-store 身份接口重新验证，同一受信身份才恢复。失败或身份变化时使私有状态失效，避免迟到响应恢复旧内容。一次性令牌 secret 离开相关界面后清除，并防止异步迟到结果重新显示。

设置页保留未保存离开保护。真实浏览器已验证：侧栏跳转取消时保留草稿，确认时丢弃未保存修改；后退取消／确认以及前进均正常。取消导航记为 canceled，未混入40次成功点击统计。连续三次点击均落到对应页面，但工具实际间隔约80–100 ms，已超过内容就绪耗时，不能宣称真实验证了小于30 ms的竞态。

最新自动测试247项通过；检查／构建及已有冒烟测试已完成。浏览器小验收仅覆盖上述导航与未保存状态，不等于全部产品功能、安全渗透或所有网络故障场景验收。
