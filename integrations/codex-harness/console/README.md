# Codex 本地控制台

独立 React 界面，只依赖共享 Zod 协议和公开测试样本，不依赖博客账号、组件、数据库或文件路径。

## 构建与访问

在仓库根目录运行 `node integrations/codex-harness/console/build.mjs`。构建产物在 `dist`（不提交 Git），由本地 runner 固定提供 `/console`；不是云端站点登录页，不应发布到托管站点。

用户主动启动本地 runner 后，使用终端的一次性本地入口。`#pair` 短期码只换取本地 HttpOnly 会话：读取后立即清理地址栏，不写浏览器存储、不记录日志。它不是 Codex 登录。

## 凭据与网页登录

- API Key 只通过已配对、同源请求发送给本机 runner。输入使用 `password`、`autocomplete=off`，用户点击提交后立即清空（无论成功/失败），不写浏览器持久存储或 URL。
- “凭据已设置，尚未验证真实调用”不代表账户、配额或模型有效。设置 key 不会自动运行测试或发起模型发现。
- 网页登录仍是独立可选入口：用户点击准备登录，再点击已校验的官方 HTTPS 链接；不自动打开或完成登录。localhost 回调须可达运行 runner 的同一台电脑。
- 云端博客/Sites 不接收 key、不托管这套 App Server 认证；不会自动切换认证方式。
- “退出 Codex”不影响网站身份；任务运行或提交结果未确认时禁用退出与凭据修改。

## 回放与真实录制

默认主操作是“回放已录制测试”：无需 Codex 登录，不启动真实推理。用户必须明确填写合法模型 ID；不会远程获取模型列表，也不会猜测默认模型。回放按模型、协议、任务类型与固定公开样本匹配；无匹配会明确提示，不自动转为真实调用。

“真实运行并录制（可能计费）”是独立次操作，必须已设置 Codex 凭据后由用户明确点击。一个任务可能包含多次模型请求；仅提交 `PUBLIC_TEST_INPUTS` 中公开样本，内容只读，不能输入私人正文录制。完成后仍保留默认回放操作，没有持续开启的真实模式开关。成功回执才说明录制已完成；不预置伪造的真实 fixture。

任务显示业务文本增量、状态与顺序/耗时。最终 `completed` 才算成功，失败不会用流式片段冒充结果；图片使用同源、服务端验证后的产物。

## 中断与恢复

- 查询失败停止自动轮询，可点“刷新状态”核对结果，不自动重新提交。
- 提交响应不确定时保留原 requestId、模式、模型与样本，并锁住输入/任务类型。用户点击“重试原请求”才原样发送；若第一次未送达，此操作会首次提交任务，真实模式可能计费，不是只读查询。
- 刷新页面会丢失内存中的恢复信息，未确认前不要关闭页面。关闭页面不代表取消，退出前请先取消并确认。
- 仅展示已知安全错误码对应的固定文案，不回显上游正文、认证材料或底层网络异常。

## 测试边界

`tests/harness-console.test.tsx` 使用 jsdom 与 HTTP 响应替身：覆盖配对、登录/失败/退出、API Key 清空与不存储、默认回放、无匹配不触发真实调用、显式录制、事件显示、取消和不确定提交原样恢复。测试不使用真实 key、不登录、不调用模型；构建与类型检查不等于真实供应商验收。
