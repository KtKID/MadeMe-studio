# Codex 本地控制台

独立 React 界面，只依赖本模块共享 Zod 协议，不依赖博客组件、数据库、账号或文件路径。

## 构建与访问

在仓库根目录运行 `node integrations/codex-harness/console/build.mjs`。构建产物位于本目录 `dist`（不提交 Git），由本地 runner 在 `/console` 提供；不是云端网站登录页，不应发布到托管站点。

用户主动启动本地 runner 后，从终端的一次性本地入口进入控制台。`#pair` 短期码只用于换取本地 HttpOnly 会话：读取后立即清理地址栏、不写存储、不记录日志。它不是 Codex 登录。正式 Codex 网页登录只在用户点击按钮后准备，再由用户点击已校验的官方 HTTPS 链接打开；不会自动登录，也不提供 API Key 或设备码入口。

## 交互边界

- 登录页的 localhost 回调必须可达运行 runner 的同一台电脑。云端博客不能托管或共享这套订阅认证。
- 控制台轮询状态/任务；查询失败停止自动轮询，可点“刷新状态”核对结果。不自动重新提交任务。提交响应不确定时锁住原输入，用户点击“重试原请求”才以同一 requestId 重新发送，避免重复创建；若第一次未送达服务端，此操作会首次提交任务（不是只读查询）；刷新页面会丢失内存恢复信息，未确认前不要关闭页面。
- 登录失败会移除失效链接并恢复重试入口；“退出 Codex”只影响本地 Codex 账号，不退出网站。运行中或提交结果未确认时禁用退出。
- 只提供润色选区和生成图片，禁用重复提交和任务运行期间类型切换；取消需服务端确认。
- 结果为纯文本或经过服务端验证的同源图片产物。未登录、工具不支持或任务失败均不伪造成功。
- 能力字段只表达适配支持，不保证当前账户、配额或模型可用。关闭页面不代表已取消后台任务；退出前请先取消并确认。
- 不显示底层网络异常或响应解析内容，避免泄漏认证材料；不将提示词写日志。

## 测试范围

`tests/harness-console.test.tsx` 使用 jsdom 和 HTTP 响应替身，覆盖短码清理、单次配对、仅点击发起登录、官方地址白名单、取消、任务轮询与失败、纯文本结果及错误脱敏。测试不会真实启动 Codex、登录、调用模型或验证供应商可用性。构建和类型检查不能代替真实同机网页登录验收。
