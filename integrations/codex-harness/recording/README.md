# 公开测试会话录制与严格回放

本模块不依赖 RPC、HTTP 客户端或 Codex 进程。`HarnessRecorder.replay()` 只读既有文件，找不到匹配样本即拒绝；不会验证密钥、拉取模型列表或回退到真实调用。

## 录制范围

- 仅接受 `public-samples.ts` 中明示的两种公开、固定测试内容，不录制任意文章或历史会话。原始请求正文不作为字段保存；记录规范化请求摘要和测试种类。
- 规范化仅为 Unicode NFC、换行格式和首尾空白，不合并内部文字。指纹绑定任务种类、规范化输入、**请求的模型 ID** 和适配协议标识。
- `HARNESS_PROTOCOL_VERSION` 表示本适配器核对的 App Server 协议/录制约定，不是动态探测用户安装的 CLI。模型 ID 可能是供应商别名；精确匹配它不证明在线模型权重或账户行为没有更新。
- 一次业务任务可包含多次模型请求，不保证固定金额或“只扣一次费”。真实运行前必须明确同意；真实失败不自动重试。

## API 与完整性

1. `begin(input)`：确认公开样本、`mode:record`、`recordConsent:true`，检查私有目录，原子创建 `.pending` 占位。已有录制或未知执行占位阻止再次付费。
2. `record(input,snapshot,secrets)`：检查当前 task/thread/turn 关联、事件顺序、首尾终态、文字增量与最终内容一致，以及真实图片产物。剥离所有旧会话 ID，仅保存允许的业务事件和相对时间。
3. 文件写入临时文件、同步后，以原子硬链接提交到最终文件名，**不覆盖已存在文件**；成功后删除临时占位。写入/检查失败不形成成功样本；已有真实任务的 `.pending` 留作未知结果保护。
4. `replay(input)`：校验请求指纹、协议/模型、文件大小、完整摘要、事件关系和图片摘要，再返回不含旧任务 ID 的结果。调用者为本次回放创建新 ID，并依次展示已记录事件。

SHA-256 用于损坏和关联检查，不是防恶意同机用户伪造的签名。专用目录须当前用户独占；进程崩溃后不自动清除 `.pending` 或猜测任务未执行。若需重新真实测试，必须另行明确处理旧样本/未知执行，不通过自动覆盖或隐式付费 fallback 实现。

## 隐私边界

不录制原始 JSON-RPC、请求头、认证消息、账号信息、stderr 或环境变量。结果含当前会话秘密、常见 token/鉴权头、官方 OAuth 授权链接、个人绝对路径或邮箱时整条拒绝保存，不把被修改的结果伪称为完整回放。失败或取消时也会拼接文字增量再检查，避免秘密被拆分到多条事件后落盘。图片原始 bytes 也检查已知秘密和敏感文本元数据，不仅检查 base64 表示。

检测不是任意私文的分类器，因此录制输入严格限定公开样本。实时原始 delta 不应先发给浏览器再脱敏：调用方须缓冲真实文本，完整校验通过后才交付文字事件。图片只接收已校验 PNG/JPEG/WebP；仅有文件 ID、不完整结果或伪图不算成功。图像魔数校验不等于完整解码器。

失败、取消可以保存为明确终态样本；回放这些样本仍失败/取消，不会触发上传媒体、修改文章或模型调用。

## 验证

`tests/harness-recording*.test.ts` 使用真实临时文件系统和虚构的公开测试结果，覆盖无样本拒绝、零网络回放、请求/模型/协议失配、秘密/图片元数据、流事件完整性、损坏文件、并发占位和不覆盖竞争。本轮没有录制真实模型会话，也没有预装伪称真实的默认 fixture。
